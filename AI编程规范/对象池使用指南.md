# 对象池使用指南

## 概述

PumpGF **不封装对象池**，直接使用 Unity 内置的 `UnityEngine.Pool` API。

- 引擎版本：Unity 2021.1+ / Tuanjie 1.9.3
- 命名空间：`UnityEngine.Pool`
- 核心类型：`ObjectPool<T>`

## 核心 API

```csharp
using UnityEngine.Pool;

// 创建池
var pool = new ObjectPool<T>(
    createFunc: () => new T(),           // 如何创建新对象
    onGet: obj => obj.SetActive(true),    // 取出时做什么
    onRelease: obj => obj.SetActive(false), // 回收时做什么
    onDestroy: obj => UnityEngine.Object.Destroy(obj), // 池满销毁时做什么
    collectionCheck: true,                // 重复释放检测（开发期间建议开启）
    defaultCapacity: 10,                  // 初始容量
    maxSize: 100                          // 池上限，超出则调用 onDestroy
);

// 取用
T obj = pool.Get();

// 回收
pool.Release(obj);

// 使用 using 语法（推荐，自动回收）
using (pool.Get(out var obj))
{
    obj.DoSomething();
} // 离开作用域自动 Release

// 清空池
pool.Clear();

// 销毁池
pool.Dispose();
```

## 使用场景与示例

### 1. 子弹 / 投射物池（高频创建销毁）

```csharp
using UnityEngine.Pool;

public class BulletPool : MonoBehaviour
{
    [SerializeField] GameObject bulletPrefab;

    ObjectPool<GameObject> pool;

    void Awake()
    {
        pool = new ObjectPool<GameObject>(
            createFunc: () => Instantiate(bulletPrefab, transform),
            onGet: go => go.SetActive(true),
            onRelease: go => go.SetActive(false),
            onDestroy: go => Destroy(go),
            collectionCheck: true,
            defaultCapacity: 16,
            maxSize: 200
        );
    }

    public GameObject Get(Vector3 pos, Quaternion rot)
    {
        var bullet = pool.Get();
        bullet.transform.SetPositionAndRotation(pos, rot);
        return bullet;
    }

    public void Return(GameObject bullet)
    {
        pool.Release(bullet);
    }

    void OnDestroy()
    {
        pool.Dispose();
    }
}
```

### 2. 特效粒子池

```csharp
public class EffectPool : MonoBehaviour
{
    [SerializeField] GameObject effectPrefab;

    ObjectPool<GameObject> pool;

    void Awake()
    {
        pool = new ObjectPool<GameObject>(
            createFunc: () =>
            {
                var go = Instantiate(effectPrefab, transform);
                var ps = go.GetComponent<ParticleSystem>();
                var main = ps.main;
                main.stopAction = ParticleSystemStopAction.None; // 禁止自动 StopAction
                return go;
            },
            onGet: go =>
            {
                go.SetActive(true);
                go.GetComponent<ParticleSystem>().Play();
            },
            onRelease: go =>
            {
                go.GetComponent<ParticleSystem>().Stop();
                go.SetActive(false);
            },
            onDestroy: go => Destroy(go),
            defaultCapacity: 8,
            maxSize: 50
        );
    }

    public void PlayAt(Vector3 position)
    {
        var effect = pool.Get();
        effect.transform.position = position;

        // 用 UniTask 延迟回收
        ReturnAfterDelay(effect).Forget();
    }

    async UniTaskVoid ReturnAfterDelay(GameObject effect)
    {
        var ps = effect.GetComponent<ParticleSystem>();
        await UniTask.Delay(TimeSpan.FromSeconds(ps.main.duration + 0.1f));
        pool.Release(effect);
    }

    void OnDestroy() => pool.Dispose();
}
```

### 3. 纯 C# 对象池（无 MonoBehaviour）

```csharp
// 适用于纯数据对象、StringBuilder、事件参数等
var builderPool = new ObjectPool<StringBuilder>(
    createFunc: () => new StringBuilder(256),
    onGet: sb => sb.Clear(),
    onRelease: sb => sb.Clear(),
    defaultCapacity: 4,
    maxSize: 16
);

// 使用
using (builderPool.Get(out var sb))
{
    sb.Append("Score: ").Append(score);
    resultText.text = sb.ToString();
} // 自动 Clear + Release
```

### 4. PooledObject using 语法（推荐模式）

`Get(out T)` 返回 `PooledObject<T>`，实现 `IDisposable`，离开 `using` 作用域自动回收：

```csharp
// ✅ 推荐：using 自动回收，不会忘记 Release
using (pool.Get(out var enemy))
{
    enemy.transform.position = spawnPos;
    enemy.ResetState();
    enemy.SetActive(true);
}
// 此处 enemy 已自动回池

// ❌ 不推荐：手动 Release 容易忘记
var enemy = pool.Get();
enemy.DoSomething();
// 忘了 pool.Release(enemy) → 对象泄漏
```

> **注意**：`using` 模式适用于"用完即还"的短生命周期场景。如果对象需要存活较长时间（如子弹飞行中），应该手动 `Get` + `Release`。

## 规范与注意事项

### ✅ 推荐做法

| 规则 | 说明 |
|------|------|
| `defaultCapacity` 设为预期峰值用量 | 避免运行时扩容 |
| `maxSize` 设为上限 | 防止池无限膨胀占用内存 |
| 开发期间开启 `collectionCheck: true` | 检测重复释放（同一对象 Release 两次） |
| 发布构建中关闭 `collectionCheck` | 避免额外开销 |
| `onGet` 中激活、`onRelease` 中失活 | 复用 SetActive 开销 |
| 池的拥有者管理生命周期 | `MonoBehaviour.OnDestroy` 中 `pool.Dispose()` |
| 归还前重置对象状态 | 清除速度、血量等，避免脏数据 |

### 🚫 禁止事项

```csharp
// 🚫 禁止从池取出对象后直接 Destroy
var bullet = pool.Get();
Destroy(bullet); // 池中的引用变成 null，下次 Get 崩溃

// 🚫 禁止重复释放
pool.Release(obj);
pool.Release(obj); // collectionCheck 会报错

// 🚫 禁止把池外对象塞进去
var externalObj = Instantiate(prefab);
pool.Release(externalObj); // 池不知道怎么处理这个对象

// 🚫 禁止 Release 后继续使用
pool.Release(bullet);
bullet.transform.position = pos; // 对象可能已被失活或回收
```

### ⚠️ 注意事项

```csharp
// ⚠️ Get 和 Release 必须在主线程
// Unity API 限制，UniTask 中也默认在主线程

// ⚠️ 回收前重置状态（避免脏数据）
void ReturnEnemy(GameObject enemy)
{
    enemy.GetComponent<Rigidbody>().linearVelocity = Vector3.zero;
    enemy.transform.SetParent(poolRoot);
    pool.Release(enemy);
}

// ⚠️ 多个池不要共享对象
// 子弹池的子弹不要放进特效池

// ⚠️ 父对象挂载
// 建议将池化对象设为池容器的子物体，避免 Hierarchy 混乱
onGet: go => { go.SetActive(true); },
onRelease: go => { go.SetActive(false); go.transform.SetParent(poolRoot); }
```

## 完整模板：通用 GameObject 池

```csharp
using UnityEngine;
using UnityEngine.Pool;
using Cysharp.Threading.Tasks;

public abstract class GameObjectPoolBase : MonoBehaviour
{
    [SerializeField] protected GameObject prefab;
    [SerializeField] protected int defaultCapacity = 16;
    [SerializeField] protected int maxSize = 100;
    [SerializeField] protected bool collectionCheck = true;

    protected ObjectPool<GameObject> pool;
    protected Transform poolRoot;

    protected virtual void Awake()
    {
        poolRoot = transform;
        pool = new ObjectPool<GameObject>(
            createFunc: CreateInstance,
            onGet: OnGetFromPool,
            onRelease: OnReleaseToPool,
            onDestroy: OnDestroyInstance,
            collectionCheck: collectionCheck,
            defaultCapacity: defaultCapacity,
            maxSize: maxSize
        );
    }

    protected virtual GameObject CreateInstance()
    {
        return Instantiate(prefab, poolRoot);
    }

    protected virtual void OnGetFromPool(GameObject obj)
    {
        obj.SetActive(true);
    }

    protected virtual void OnReleaseToPool(GameObject obj)
    {
        obj.SetActive(false);
        obj.transform.SetParent(poolRoot);
    }

    protected virtual void OnDestroyInstance(GameObject obj)
    {
        Destroy(obj);
    }

    protected virtual void OnDestroy()
    {
        pool?.Dispose();
    }
}
```

子类继承示例：

```csharp
public class BulletPool : GameObjectPoolBase
{
    public GameObject Get(Vector3 pos, Quaternion rot)
    {
        var bullet = pool.Get();
        bullet.transform.SetPositionAndRotation(pos, rot);
        return bullet;
    }

    public void Return(GameObject bullet)
    {
        bullet.GetComponent<Rigidbody>().linearVelocity = Vector3.zero;
        pool.Release(bullet);
    }
}
```

## 速查表

| 需求 | 方法 |
|------|------|
| 取出对象 | `pool.Get()` |
| 取出并自动回收（短生命周期） | `using (pool.Get(out var obj)) { ... }` |
| 回收对象 | `pool.Release(obj)` |
| 清空池 | `pool.Clear()` |
| 销毁池 | `pool.Dispose()` |
| 当前池中数量 | `pool.CountInactive` |
