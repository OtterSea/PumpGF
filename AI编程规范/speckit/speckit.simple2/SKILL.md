# SpecKit: Simple2 — 极简需求直达实现

## 用途

拿到需求后直接分析并实现，不停下来等确认。适用于改动集中在 1-5 个文件的小需求。产物：`.specify/<主题>/<N>.simple.md` + 实际代码。

## 复杂度阈值（仅做标注，不中断）

| 维度 | 阈值 |
|------|------|
| 涉及文件数 | > 5 个 |
| 新增类/模块 | > 2 个 |
| 跨系统联动 | > 3 个独立系统 |
| 新增事件 | > 2 个 |
| 新增 UI 页面/模块 | 任何 |
| 配置表变更 | 新增表 |

超标时在产物中标记 `complexity: oversize`，不中断流程。

## 工作流（单步执行，全程不停顿）

### 1. 分析（静默）

- 理解需求
- Grep/Glob/Read 定位相关文件
- 评估复杂度（超标仅标注）

### 2. 实现（直接动手）

- 按逻辑顺序逐文件编码
- 遵循 constitution 编码规范
- 自检：事件配对、空引用、代码风格

### 3. 写产物存档

写入 `.specify/<主题>/<N>.simple.md`：
- frontmatter: workflow, date, status, complexity
- 正文: 需求、变更文件表、备注

### 4. 报告完成

向用户简要报告改了什么，一两句话。

## 约束

- 不产出 spec/plan/tasks
- 遵循 constitution 编码规范
- 不整读大文件
- 引用真实路径和类名
