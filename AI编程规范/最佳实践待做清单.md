## 每篇文档的标准结构（模板待生成）

每篇最佳实践文档应包含以下章节：

```markdown
# [模块名] 最佳实践

## 1. 模块职责（一句话）
## 2. 核心 API 速查
## 3. 标准使用模式（3-5 个最常见场景 + 代码示例）
## 4. 禁止做的事（引用约束清单对应条目）
## 5. 与其他模块的协作模式
## 6. 常见错误与排查
## 7. 完整示例（一个从零到完整的使用案例）
```

## 优先级说明

- **🔴 P0**：角色3C系统重构中暴露出的高频误用模块，AI 最容易在这些模块上犯错。必须最先编写。
- **🟡 P1**：游戏开发中高频使用的模块，AI 需要正确范例才能生成合格代码。
- **🟢 P2**：使用场景相对明确、API 较简单的模块，可后续补充。
